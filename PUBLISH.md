# Публикация с сохранением истории

Проект уже является Git-репозиторием. Не загружайте файлы одной операцией через
Upload files: это не перенесёт локальную историю разработки.

1. В аккаунте mastermind878 создайте публичный репозиторий `netplan` без README,
   .gitignore и лицензии (пустой репозиторий).
2. В терминале откройте папку проекта, содержащую `.git`.
3. Проверьте историю: `git log --oneline`.
4. Для нового пустого репозитория выполните:

```text
git remote add origin https://github.com/mastermind878/netplan.git
git push -u origin main
```

Если origin уже добавлен, сначала посмотрите `git remote -v`; не добавляйте его
повторно. Выполните вход в GitHub в стандартном диалоге Git Credential Manager.
Не помещайте пароль или токен в код, URL, README или сообщения чата.

5. Во вкладке Actions дождитесь окончания NetPlan CI. При ошибке откройте
   конкретный упавший шаг; результат нельзя считать готовым до зелёного статуса.
6. Проверьте artifact `netplan-source` и доступность репозитория без входа.
7. Передайте преподавателю URL репозитория, URL успешного run и описание из README.

Архив `netplan-with-history.zip` содержит исходники и `.git` с историей.
Распакуйте его целиком; не удаляйте скрытую папку `.git`.
История создана по фактическим этапам работы с ИИ-ассистентом. Локальный автор
коммитов обозначен `NetPlan project`; это не удостоверение личности студента.
